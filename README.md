# 📊 PhonePe Transaction Analytics Dashboard

A Power BI dashboard built to analyze **300,000+ PhonePe transactions**, uncover payment trends, user behavior, transaction success rates, and business insights through interactive visualizations.

---

# 📌 Project Overview

Digital payments generate massive amounts of transactional data every day. The objective of this project is to transform raw transaction data into meaningful business insights using Power BI.

The dashboard helps answer questions like:

- How many transactions were completed?
- What is the total transaction value?
- Which services are used the most?
- Which age group contributes the highest transactions?
- How reliable is the payment system?
- What are the major reasons behind failed payments?
- How do transaction patterns change throughout the week?

# 📊 Key Business Insights

- ✔️ Analyzed over **300,000 transactions**
- ✔️ Digital payment success rate reached **96%**
- ✔️ **Gen X** users generated the highest transaction activity
- ✔️ **Money Transfer** recorded the highest transaction volume
- ✔️ Weekdays account for **71.6%** of total transactions
- ✔️ Payment failures are primarily driven by server issues, incorrect PIN entries, and insufficient balance
